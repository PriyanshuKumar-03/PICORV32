# PICORV32
Executed a complete end-to-end ASIC physical design flow using the GPDK 45 nm process for the open-source PicoRV32 RISC-V processor (picorv32.v), taking the design from RTL synthesis through place-and-route, I/O pad integration, and final GDSII signoff. Conducted extensive design-space exploration across multiple target frequencies and physical/synthesis optimizations to evaluate power-performance-area (PPA) trade-offs. Benchmarked each implementation using a custom multi-objective Figure of Merit—defined as FOM = Normalized Clock Frequency / (Normalized Total Power × Normalized Total Die Area), normalized against 400 MHz, 10 mW, and 50,000 µm²—to identify and deliver the optimal physical layout maximizing overall efficiency.
